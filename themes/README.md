# Canonical Themes Layer

This directory serves as the conceptual source of truth for all themes in **Best Themes**.

---

## 📁 Organization

- `upstream/` — Community themes preserved in their authentic, unmodified form with full upstream licensing and attribution.
- `modified/` — Community themes adapted with intentional modifications or normalized for cross-editor visual parity.
- `custom/` — Original custom themes built from scratch using our canonical semantic token design system.
