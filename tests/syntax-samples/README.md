# Syntax Test Corpus

This directory is intended to contain lightweight, representative code samples across various programming languages.

When evaluating themes for cross-editor semantic consistency, open these files simultaneously in VS Code, Zed, and Neovim to visually check that semantic constructs (keywords, modifiers, strings, functions, types, constants, etc.) match as closely as possible.

Supported target languages will include:
- `rust.rs`
- `typescript.ts`
- `javascript.js`
- `python.py`
- `go.go`
- `java.java`
- `cpp.cpp`
- `html.html`
- `css.css`
- `json.json`
- `toml.toml`
- `lua.lua`
